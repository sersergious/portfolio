# About

This was my group project for Mobile Application Development. It’s a comprehensive project that includes an MVVM-based Android app for browsing and storing recipes. There are no plans to expand this project further.

# Features

- Offline first storage using Room ORM and SQLite DB.
- Retrofit API for fetching and saving recipes.
- Ability to select favorite recipes.
- User/Admin-based sign-up and sign-in functionality.
